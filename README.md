# ao-library-world — Library World Portal [CLEAN REBUILD]

A from-scratch rebuild of the Library World portal for **anomartsy.xyz** — the AO Universe homeworld. Built clean in git. **No Manus.**

## What this is

The Library World is home base: read a story, play a game, color a world, make something of your own — and everything earns Anom Coin (10 AC = $1).

First clean page: `index.html` — the portal, with Moonberry Farm, Color Corner, Pixel & Dot, Tater / Ozka / Wendigo (AO Security), the Archive, the Collection, the four Houses, Mood Memes & Social, Reading Nooks, and the Vault.
